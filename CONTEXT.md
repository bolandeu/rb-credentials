# rb-credentials

Разрешение именованных секретов без хранения и печати значений: пакет знает **имена**, окружение — **адреса**.

## Словарь

**Credential** — секрет (`SecretStr`) с необязательными сроком жизни и областями (scopes).

**Адрес** — откуда взять секрет: `env:ИМЯ` (переменная окружения), `keyring:сервис[:пользователь]` (системное хранилище), или произвольная функция (`CallableCredentials`).

**Провайдер** — объект, который умеет отдать `Credential` по имени (`CredentialProvider`). Провайдеры пробуются по порядку.

**Разрешение** — `resolve_credential(*providers, name=...)`: первый провайдер, давший пригодный секрет, побеждает; если ни один — `CredentialsUnavailable`.

_Избегать_: «хранилище секретов», «конфиг с ключами» — этот пакет ничего не хранит.
